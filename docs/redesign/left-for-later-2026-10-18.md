# Left for later: what the Appmilla Factory redesign did not build

Written 18 October 2026, at the end of stage 3 of the redesign. The approved design shows some
things the dashboard cannot show honestly yet, because the records behind them do not exist or a
behaviour is not built. They were left out on purpose. Each one can be added when its data or
behaviour arrives.

| Left out | Why |
|---|---|
| The Mission screen and its place in the top menu | There is no mission page and no mission data in the view the pages read. |
| Cost and spend figures | Cost reporting arrives with Part B's cost feed. Until then every cost tile and cell says "Not measured", never a zero or an example figure. |
| The chat as a sliding panel that opens and closes | The chat today is a fixed column on wide screens and its own page on narrow ones. The sliding panel, its dimmed background and its close button wait until the chat has open and close behaviour. |
| "Decide in Slack" as a link | The records carry no address for the Slack conversation, so it is plain words. It becomes a link when the address is recorded. |
| The client's reports page | There is no page for it yet. |
| "Suggest a change" | Nothing in the dashboard records a suggestion, and the dashboard only reads. |
| Time per stage, machine time and "where the time went" | The records do not hold when each stage started and ended. |
| Plan against actual on a project's page | That view carries no plan to compare against. The weekly report still shows its own plan comparison. |
| Agents, machines and the other data feeds on the Fleet page | There is no data for them in the view the page reads. |
| Downloading a report as a spreadsheet | Not built. The printable report is there. |
